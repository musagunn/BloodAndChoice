# 🩸 Blood & Choice

**Blood & Choice**, Unity ve C# kullanılarak geliştirilmiş, Reigns tarzı, hikaye odaklı ve stratejik karar verme mekaniklerine sahip bir mobil oyundur. 

Oyuncular, karşılarına çıkan olaylara verdikleri tepkilerle krallığın dengesini korumaya çalışır. Her karar, oyunun temel dinamikleri olan ekonomi ve sağlık sistemlerini doğrudan etkiler.

## 🎮 Temel Özellikler
* **Karar Mekanizması:** Sağa veya sola kaydırarak hikayenin gidişatını belirleme (Swipe mekaniği).
* **Dinamik Sistemler:** Yapılan seçimlerin "Sağlık" ve "Ekonomi" parametreleri üzerindeki anlık ve uzun vadeli etkileri.
* **Modüler Kod Mimarisi:** C# ile geliştirilmiş, sürdürülebilir ve genişletilebilir (`GameManager`, `CombatManager`, `CardController`) sistem tasarımı.

## 🛠️ Kullanılan Teknolojiler
* **Oyun Motoru:** Unity 3D (2D Mobile Build)
* **Programlama Dili:** C#
* **Versiyon Kontrolü:** Git & GitHub

## 📂 Kurulum ve Geliştirme (Geliştiriciler İçin)
Bu projeyi kendi bilgisayarınızda çalıştırmak için:
1. Repoyu bilgisayarınıza klonlayın: `git clone https://github.com/musagunn/BloodAndChoice.git`
2. Unity Hub'ı açın ve `Add project from disk` seçeneği ile klonladığınız klasörü seçin.
3. Proje açıldığında `Assets/Scenes` klasörü altındaki ana sahneyi çalıştırın.
